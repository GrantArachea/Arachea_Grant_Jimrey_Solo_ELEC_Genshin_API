API Documentation

genshin.jmp.blue used for JSON + images

1. Base URL

https://genshin.jmp.blue

2. Endpoints (3+)

  • GET /characters
  • GET /characters/{id}
  • GET /weapons
  • GET /weapons/{id}
  • GET /artifacts
  • GET /artifacts/{id}
  • GET /{type}/{id}/icon (images)
  • GET /characters/{id}/card (character card art)
  • GET /artifacts/{id}/flower-of-life (artifact art)

3. Required Parameters

Path parameters:

  • {type} and {id}

4. Authentication

None (no API key, no OAuth).

5. Sample JSON (fields used)

Example: GET /characters/nahida

{
  "name": "Nahida",
  "title": "...",
  "vision": "Dendro",
  "weapon": "Catalyst",
  "nation": "Sumeru",
  "rarity": 5,
  "description": "..."
}

6–10. fetch, DOM, validation, loading, errors

  • fetch() + async/await
  • Cards + images + modal
  • Error handling: invalid input, no results, failed API call
  • Loading state: spinner + text
  • Buttons disabled while loading
  • Element aura hover: uses vision field from character detail JSON
